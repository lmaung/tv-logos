# Nuvio collection imports

Ready-to-import collection profiles using artwork from this repository.

## Files

- `nuvio-streaming-networks-import.json` — streaming-service TV networks
- `nuvio-trending-popular-tv-import.json` — TV discovery collection
- `nuvio-trending-popular-movies-import.json` — movie discovery collection
- `nuvio-three-collections-complete-import.json` — all three collections in one import

The TV collection uses the official Nuvio Catalog Addon
(`com.nuvio.tmdb.catalogs`) for its dynamic `new-and-returning-series` source.
Install `https://catalog.nuvio.tv/manifest.json` before importing that collection.

Artwork URLs target the `nuvio-collections` branch of this repository.
